星桥文档服务：部署手册（自编虚构项目 v1.0）

本文件是本项目原创演示语料，不是第三方官方部署指南。允许随演示项目复制、修改和使用。

本地开发命令从项目根目录运行。先设置 MODEL_MODE，再执行 python -m scripts.ingest；完成索引后用 python -m uvicorn app.main:app --host 127.0.0.1 --port 8001 启动。未构建索引时仍能检查进程，但查询不可用。

Docker 使用 api 和 ingest 两个服务，共用同一镜像并采用非 root 用户。语料卷只读，ingest 的索引卷可写，api 将同一个索引卷挂载为只读。构建镜像期间不调用模型，也不复制 .env 和本地索引。

容器内监听 0.0.0.0:8001，宿主机只映射 127.0.0.1:8001:8001。仅在容器内部监听 127.0.0.1 会导致端口映射无法访问；本地开发直接监听 127.0.0.1 则是正确行为。

首次部署顺序是 docker compose build、docker compose run --rm ingest python -m scripts.ingest、docker compose up api。API 容器不承担索引构建，不能把索引不存在伪装成已就绪。

恢复流程：先修复语料、配置或磁盘权限，再由维护者显式运行 ingest。只有构建自检和指针发布成功后，新索引才生效。若当前构建失败，保留旧索引用于排查；不承诺跨版本迁移或并发发布能力。
