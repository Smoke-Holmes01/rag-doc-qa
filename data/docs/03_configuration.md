# 星桥文档服务：配置说明

本文件为星桥 v1.0 自编演示资料，不是云平台配置规范。

## 模式隔离

MODEL_MODE 只能为 mock 或 live，默认 mock。两种模式使用独立索引和独立评测报告。evaluate 的显式 --mode 参数优先于环境中的 MODEL_MODE，不得读取另一模式的索引。

live 必须分别配置聊天及嵌入的适配器、接口地址、API Key 和模型名。配置缺失时返回 CONFIG_INVALID，只列变量名，不能打印密钥或配置值。

## 切分和预算

CHUNK_MAX_CHARS 默认 800，CHUNK_OVERLAP_CHARS 默认 100，重叠必须小于片段上限。优先保持标题和完整段落，只有超长段落使用重叠切片。

CONTEXT_MAX_CHARS 默认 4000，是包含来源封装的字符预算，不是精确 token 数。放不下完整片段时应少放片段，不得偷偷截掉例外条款。

## 超时和批量

HTTP_TIMEOUT_SECONDS 默认 30 秒，连接阶段最多等待 5 秒，读取、写入与连接池等待分别使用配置的超时。所有模型调用均不自动重试，限流和认证错误不会切换到其他模型。

EMBEDDING_BATCH_SIZE 默认 16，只用于离线分批嵌入文档；在线请求一次仅嵌入当前问题。批量大小还必须符合所用供应商的输入限制。
